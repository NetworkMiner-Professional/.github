## What Is NetworkMiner Professional

NetworkMiner Professional is a review helper for a packet capture you already possess. NetworkMiner Professional pcap file is the starting point: a class sample, a lab exercise, or a capture taken on a network you administer. NetworkMiner Professional host list turns that file into names of hosts. You do not need to collect someone else’s traffic to learn the screens.

NetworkMiner Professional session list shows which hosts talked. NetworkMiner Professional file list shows files the capture already contained. NetworkMiner Professional parameter tab shows parsed fields from that same file. A student can walk a provided sample. An admin can review a capture from their own network after an incident they are responsible for. The work is reading a file you are allowed to hold.

Open one capture and stay with it. NetworkMiner Professional pcap file, NetworkMiner Professional host list, and NetworkMiner Professional session list tell the story of who appeared and who talked. NetworkMiner Professional file list and NetworkMiner Professional parameter tab are the closer look. Keep notes in your lab book rather than treating the capture as a hunting ground outside your permission.
